# Control Interface

The **Control Interface** is a foundational GridWorks crafting component.

It represents the connection point between a device and the GridWorks automation layer and is used in the progression of more advanced sensors, controllers, monitors, alarms, and control devices.

## What it is for

Unlike a sensor or controller, the Control Interface is primarily an **ingredient/component** rather than a complete automation system by itself.

It is used to build devices that participate in the GridWorks Control Bus.

## Progression role

GridWorks' survival progression intentionally starts with familiar vanilla materials such as copper, redstone, and quartz, then uses earlier GridWorks components in more advanced recipes.

The Control Interface is one of those core progression pieces.

For example, higher-level devices such as controllers and monitoring equipment build on established GridWorks control components rather than being isolated recipes.
